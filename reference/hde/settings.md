# Settings

The settings <span class="keyseq"><kbd>Ctrl</kbd><kbd>F1</kbd></span> can be found in the ![](../../images/hde/settings-icon.png) menu in the top right corner of the editor window:

![](../../images/hde/settings.png)

## Local Settings
You can also provide a local settings file via commandline options when you start up vvvv.exe:

    --settings C:\path\to\settings.xml
