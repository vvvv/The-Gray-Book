# Projection Mapping

Since requirements for projection mapping are rather diverse, vvvv comes with support for different options:

The following projector auto-calibration systems are integrated:

- [VIOSO](https://vioso.com/)
- [Scalable Display Systems](https://www.scalabledisplay.com/)
- If you need any other existing system integrated, don’t hesitate to [get in touch](mailto:devvvvs@vvvv.org).

Alternatively vvvv also ships with tooling that helps you build custom projection mapping workflows. See the [Projection Mapping](https://vvvv.org/packs/?c=Projection%20Mapping) section in the packs browser for all options.
